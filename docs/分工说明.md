# 游子衣项目分工说明

## 成员分工

### 杨云天、刘至晗、乔钰成 —— 前期调研与商业规划

- 市场调研与竞品分析
- 产品定位与功能边界定义
- 商业计划书撰写

### 乔钰成 —— 总体架构设计与全栈开发

**设计**
- 设计 Monorepo 目录结构（`apps/web`、`apps/miniapp`、`apps/server`、`packages/types`、`packages/shared`）
- 设计 API 协议与统一响应结构（`{ code, data, message }`）
- 设计数据库 Schema（Prisma + PostgreSQL/Redis），含用户、健康记录、家庭关系等核心表
- 设计超时预警状态机（24h / 36h / 48h 三级告警阈值与事件分发）
- 设计路由守卫逻辑（Onboarding → 家庭连接 → 主面板的跳转闭环）

**调研**
- 技术选型调研（Node.js / NestJS、Prisma ORM、React/Vite、Zustand 等方案的对比与确定）
- 参与市场调研、竞品分析与商业计划书撰写（与杨云天、刘至晗共同完成）

**开发**
- 后端：Node.js + Prisma + Redis，实现认证、每日打卡、家庭连接、预警等核心接口
- Web 端：React + Vite + Tailwind CSS，实现大屏动效、天气瓶 3D 渲染、数据可视化
- 小程序端：原生微信小程序，实现适老化打卡面板与家庭互动
- 共享层：维护 `packages/types` 类型定义与 `packages/shared` 工具常量，确保三端接口协议一致
- 鸿蒙对接：定义并维护与鸿蒙端的接口协议，协调三端联调

**调试**
- 三端联调与接口验证（本地端口、代理、Mock 环境搭建与排障）
- 跨端数据一致性校验（状态读取路径、字段命名、响应结构同步）

**部署**
- 云服务器环境搭建：Nginx 反向代理配置、SSL 证书申请与续期
- PM2 进程管理：后端服务守护、崩溃自动重启、开机自启
- CI/CD 流水线配置与 GitHub 仓库管理
- 构建产物权限修复与静态资源部署

**文档**
- 维护 `docs/API接口规范.md`、技术开发规则、云服务器部署指南等核心文档
- 接口变更时同步更新共享类型、三端代码与相关文档

**设计**
- 鸿蒙端页面路由与导航结构设计
- 组件树划分与状态管理方案设计

**调研**
- ArkTS / ArkUI 技术栈调研与可行性评估
